# Python One-Liners

A daily updated JSON feed of high-quality Python one-liners.

## Usage

```js
fetch('https://rahulwork247.github.io/python-one-liners/data/one_liners.json')
  .then(r=>r.json())
  .then(data=> console.log(data[0]));
```
